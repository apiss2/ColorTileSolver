# 検証結果

以下は作成時の検証記録です。ソース公開準備時の再検証結果は末尾に追記しています。

## 対象

ColorTile Solver 1.0。2026年10月29日に作成したWindows x64版と、その共通C++コードを検証しました。

Windows版はLLVM-MinGW 20261020でビルドしました。GUIの依存先はWindows標準のライブラリとWindowsに含まれるUCRTです。Python、Qt、追加のC++ランタイムDLLは配布物に必要ありません。

実行検証にはLinux上のWine 9.0を使用しました。Windows 10／11の実機での操作は未確認です。以下の速度は、この検証環境での観測値であり、すべてのPCや盤面で同じ時間と手数を保証するものではありません。

## 探索の正しさ

独立して実装した幅優先探索と比較し、全消し可能かどうか、全消しに必要な最小クリック数、返された各手の合法性を確認しました。

| 検証 | 件数 | 結果 |
|---|---:|---|
| 3×3、空白と2色の全組合せ | 19,683 | 全消し可否と最短手数が一致 |
| 3×4、4×4の乱数盤面 | 各500 | 全消し可否と最短手数が一致 |
| 別実装の参照探索による1色全組合せと3色乱数盤面など | 2,814 | 最短手数、消去対象、全経路の再生が一致 |

2,814件の参照比較はLinux版とWindows実行ファイルの双方で通過しました。これには元の実装で問題となっていた3枚のT字配置と、2色を2枚ずつ同時に消す配置も含まれます。

追加で、不正な色と盤面寸法、短時間の探索終了、開始前のキャンセル、探索中のキャンセルを検証しました。タイムアウトやキャンセルを最短性の証明として扱わないことも確認しました。

## 添付画像の認識

今回提供された画像は641×440ピクセルです。23列15行の格子として読み取り、全345マスについて、独立した手動位置指定による読み取りと一致しました。タイルは200枚で各色20枚、不確かな色の判定は0件でした。

元画像を含む15種類の変換画像でも、すべてのマスの色が一致しました。拡大率0.5～3倍、余白追加、縦横比変更、盤面部分だけの切り抜き、JPEG品質95／85／70／50を含みます。JPEG品質50では2マスを不確かと表示しましたが、分類結果は一致しています。

無地の画像は盤面として受理しません。画像寸法、RGBバッファの長さ、格子の範囲、未知の暗色の警告も検証しました。

## Windows版のGUIを通した検証

GUIから画像を読み込み、探索を開始して結果を表示する一連の処理を実行しました。

| 入力 | 指定時間 | 結果 |
|---|---:|---|
| 今回の200枚の画像 | 2秒 | 75手の全消しを取得、最短性未確認と表示 |
| 同じ画像を別試行 | 2秒 | 73手の全消しを取得、最短性未確認と表示 |
| 同じ画像の短時間指定 | 0.15秒 | 77～78手の全消しを取得、最短性未確認と表示 |
| 3枚のT字配置 | 10秒 | 1手を最短確定、約0.007秒で終了 |
| 隣接する同色2枚 | 0.15秒 | 全消し不能と判定 |

200枚の画像の2秒試行は、約2.003～2.006秒で探索処理を終えました。認識枚数、全消し手数、残数、最短性の表示、指定時間を、GUIの診断出力でも照合しました。

200枚の画像について、真の最短手数の証明には到達していません。このため、配布アプリと本報告では73手または75手を厳密な最短解として扱っていません。

日本語での画面表示も確認しました。また、10秒探索を途中で停止して手順を保持すること、前後移動、最初の手順への復帰、再探索、計算中にウィンドウを閉じる操作を検証しました。停止から操作可能になるまで約0.35秒、再探索中の終了は約2.03秒で、アプリは正常終了しました。これらもWineでの観測値です。

## 再現方法

[README.md](../README.md) のビルドとテストの項を参照してください。探索の全組合せテストは `tests/test_solver_exhaustive.cpp`、別の参照比較と停止処理のテストは `tests/test_core.cpp`、画像変換テストは `tests/test_recognition.py`、GUIの操作と終了の検証は `tests/test_gui_windows.cpp` にあります。

GUIの診断用引数も用意しています。

```powershell
.\ColorTileSolver.exe --smoke-solve 2 --capture gui.bmp .\examples\sample.png
```

指定時間の探索後に画面を保存し、`gui.bmp.json` へ認識枚数、手数、残数、最短性、指定時間と実行時間を書き出します。診断用の指定がない通常起動では、このようなファイルを自動作成しません。
